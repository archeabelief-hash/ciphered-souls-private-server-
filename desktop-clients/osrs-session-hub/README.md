# OSRS Session Hub (Safe Multi-Client Manager)

## Purpose
This tool allows you to run multiple OSRS/RuneLite clients and manage them from a single desktop app window.

## IMPORTANT (READ)
- NO automation
- NO input broadcasting
- NO botting
- NO client modification

This tool only launches and organizes windows.

## Setup
1. Install Node.js
2. cd into this folder
3. run: npm install
4. run: npm start

## Features (MVP)
- Launch multiple clients
- Central control UI

## Planned Features
- Window tiling (grid layouts)
- Session presets
- Timers (farming, GE flips, etc.)
- CPU/RAM monitor

## Future Expansion
- RuneLite detection
