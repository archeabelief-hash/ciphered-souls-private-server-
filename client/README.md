# Ciphered Souls Desktop Client

## Windows Quick Start

1. Open terminal in project root
2. Run:

npm install

3. Double click:

client/windows/CipheredSoulsClient.bat

## What this does

- Starts your Ciphered Souls server
- Opens the game in your browser like a client

## Notes

- This is Phase 1 desktop client (browser wrapped)
- Next upgrade will be full EXE client (Electron)
- Do NOT close the server window while playing
