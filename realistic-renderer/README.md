# Ciphered Souls — Realistic Renderer Prototype

Standalone client-side Godot 4 renderer prototype. It does not modify or require the existing Ciphered Souls server.

## Run
1. Install Godot 4.x.
2. Open `realistic-renderer/project.godot`.
3. Press **F6/F5**.

## Controls
- **WASD** — move
- **Shift** — sprint
- **Q / E** — down / up
- **Hold right mouse + move mouse** — camera look
- **Esc** — release mouse

## Included scene
Procedural woodland, path, water, stone ruins, directional lighting, shadows, sky, fog, filmic tonemapping and an exploration camera. Everything is generated locally from the project; there are no external asset dependencies.

This branch is intentionally client-side and isolated from the existing game/server.
